# Jared Horn portfolio

A static, responsive portfolio built from the supplied site and its existing photography and video links. No build step or package installation is required.

## Preview

Open `index.html` in a browser, or run `python3 -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Publish with GitHub Pages

Copy the contents of this folder to the root of your Pages repository (or the configured publishing folder), commit, and push. Keep `index.html`, `style.css`, `script.js`, `assets/`, and `photo/` together. Existing filenames `photography.html`, `video.html`, and `cv.html` remain valid.

## Editing

- Page content is in the four root HTML files.
- Colors, spacing, layout, and responsive behavior are in `style.css`.
- The photo viewer is in `script.js`; it works with keyboard arrows and Escape.
- The films are embedded from the YouTube IDs already in the old portfolio. An internet connection is needed to play them.
- The public About page omits the old CV's private reference contacts. Add a downloadable résumé separately if you want one.

Before publishing, review the first-person About copy, contact email, social links, photo selection and image descriptions. Several older image descriptions are intentionally broad where the original archive did not provide captions.
